How a metric earns trust

Each gate is enforced in code and asserted in CI on every push.

Governed

One definition in metrics/registry.yml with a declared source of truth and an owning org — GTM Ops or Finance. Registry must match the published mart.

Fresh

Every upstream source loaded within the freshness window (7 days of the as-of date). Stale inputs fail the gate before anyone reads the number.

Reconciled

The published value must match an independently recomputed reference within tolerance. This is the gate that catches a metric quietly sourced from the wrong system.
